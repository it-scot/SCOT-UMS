# Routes

TanStack Start uses file-based routing. Every `.tsx` file in this directory is a route. Screen components live in `src/pages` and are imported from here.

`routeTree.gen.ts` is generated by the TanStack Router plugin. Regenerate it by running the dev server rather than editing it by hand.

| File | URL | Screen |
| --- | --- | --- |
| `index.tsx` | `/` | Employee Dashboard |
| `hr.tsx` | `/hr` | HR Dashboard |
| `admin.tsx` | `/admin` | Admin & Logistics |
| `helpdesk.tsx` | `/helpdesk` | IT Helpdesk |
| `__root.tsx` | — | App shell. Keep `<Outlet />`. |
